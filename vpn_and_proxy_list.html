Инструкция по настройке

  1. Установите приложение HAPP на ваше устройство.
  2. Скопируйте вашу ссылку подписки на VPN/Прокси.
  3. Нажмите (+) → Вставить из буфера обмена
    (Добавлять подписку лучше при стабильном Wi-Fi)
  4. Обновите подписку (значок 🔄), затем нажмите на значок скорости и выберите сервер с минимальным пингом (МС).

В настройках приложения:

  • Зайдите в "Подписки" и выберите Сортировать по пингу.
  • Android Выберите Прокси для выбранных приложений → ВКЛ и отметьте нужные. Остальные будут работать без VPN.

Обход блокировок

Если путь к серверам преграждён незримой стеной — откройте настройки HAPP и включите функции обхода. Они разбивают сигнал на мелкие части, делая его невидимым для блокировок.
